# Checklist de aprendizagem

## Conceitos fundamentais

- [ ] Entendi o modelo OSI
- [ ] Entendi o modelo TCP/IP
- [ ] Entendi endereçamento IP e MAC
- [ ] Entendi TCP e UDP
- [ ] Entendi roteamento e roteadores
- [ ] Entendi DNS, HTTP e HTTPS
- [ ] Entendi SSH, FTP, SMB e SMTP
- [ ] Entendi como usar Wireshark
- [ ] Entendi diagnóstico de falhas
- [ ] Entendi segurança básica de rede

## Atividades práticas

- [ ] Capturei tráfego com Wireshark
- [ ] Examinei uma requisição HTTP
- [ ] Analisei uma consulta DNS
- [ ] Verifiquei um handshake TCP
- [ ] Diagnostiquei um problema de rede
- [ ] Revisei e documentei resultados
