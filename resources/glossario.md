# Glossário de redes

## Conceitos básicos

- Router: encaminha pacotes entre redes
- Switch: conecta dispositivos locais
- Firewall: controla tráfego
- NAT: traduz endereços privados para públicos
- MAC: endereço físico da interface
- IP: endereço lógico da rede
- Porta: identificação de serviço ou aplicação
- Segmento: unidade de transporte TCP
- Pacote: unidade de rede IP
- Quadro: unidade de enlace

## Termos úteis

- Latência: tempo de ida e volta
- Throughput: volume de dados transferido
- Jitter: variação de atraso
- MTU: maior tamanho de pacote sem fragmentação
- Handshake: troca inicial de mensagens de estabelecimento de conexão
