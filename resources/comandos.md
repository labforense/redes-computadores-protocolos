# Comandos úteis

## Diagnóstico básico

```bash
ping exemplo.com
tracert exemplo.com
nslookup exemplo.com
ipconfig
ifconfig
arp -a
netstat -an
```

## HTTP e DNS

```bash
curl -I https://example.com
dig example.com
nslookup example.com
```

## Wireshark

- Captura de pacotes em interfaces ativas
- Filtros por protocolo
- Análise de fluxo e conversas

## Importante

Use esses comandos como apoio para compreender a vida real da rede, não apenas como prática de terminal.
