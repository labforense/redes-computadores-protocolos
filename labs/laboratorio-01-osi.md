# Laboratório 01 — Modelo OSI

## Objetivo

Entender como os dados trafegam de uma aplicação até o meio físico e de volta.

## Exercício

Descreva os passos de uma requisição web, identificando as camadas:

- Aplicação
- Apresentação
- Sessão
- Transporte
- Rede
- Enlace
- Física

## Perguntas

1. Qual camada gera a requisição HTTP?
2. Qual camada adiciona o endereço IP?
3. Qual camada entende o endereço MAC?
4. O que acontece quando o pacote sai do computador para a rede?

## Entrega

Escreva um fluxo completo de comunicação em texto ou diagrama.
