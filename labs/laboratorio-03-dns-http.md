# Laboratório 03 — DNS e HTTP

## Objetivo

Entender a interação entre nomeação e navegação web.

## Exercício

1. Acesse um domínio qualquer em um navegador
2. Registre o que acontece na sequência:
   - consulta DNS
   - conexão TCP
   - requisição HTTP
   - resposta HTTP
3. Observe os headers e códigos de status

## Perguntas

1. Qual a função do DNS?
2. O que acontece quando o domínio não resolve?
3. Como o navegador identifica que a comunicação é segura?

## Entrega

Descreva o fluxo completo da navegação do domínio até a resposta do servidor.
