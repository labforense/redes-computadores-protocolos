# Laboratório 05 — Troubleshooting de rede

## Objetivo

Diagnosticar falhas comuns em redes e protocolos.

## Cenários

- Site não abre
- DNS não resolve
- Porta bloqueada
- Conexão lenta
- Servidor inacessível

## Comandos sugeridos

- ping
- traceroute / tracert
- nslookup / dig
- ipconfig / ifconfig
- arp
- netstat
- curl

## Perguntas

1. Como validar se o problema está em DNS?
2. Como identificar se a porta está bloqueada?
3. O que diferencia falha de roteamento de falha de serviço?

## Entrega

Descreva o passo a passo de diagnóstico para cada cenário.
