# Laboratório 04 — Wireshark

## Objetivo

Aprender a ler e interpretar tráfego de rede real.

## Exercício

1. Abra o Wireshark
2. Capture o tráfego em uma interface ativa
3. Filtre por DNS e HTTP
4. Observe a sequência de pacotes
5. Identifique:
   - endereço IP origem e destino
   - porta do protocolo
   - requisição e resposta
   - presença de TLS/HTTPS

## Perguntas

1. Como identificar uma consulta DNS?
2. Como reconhecer uma conexão TCP?
3. O que indica uma resposta HTTP 200?

## Entrega

Faça um relatório com imagens ou descrições dos pacotes observados.
