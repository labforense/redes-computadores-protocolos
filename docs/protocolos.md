# Protocolos essenciais

## HTTP/HTTPS

- HTTP: comunicação web em texto claro
- HTTPS: HTTP sobre TLS
- Uso de portas 80 e 443
- headers, métodos, status codes

## DNS

- Tradução de nomes para IP
- Port 53
- Consultas recursivas e iterativas
- Registros: A, AAAA, MX, NS, CNAME, TXT

## SSH

- Acesso remoto seguro
- Porta 22
- Criptografia e autenticação
- Base para administração remota segura

## FTP

- Transferência de arquivos
- Portas 21 e dados em portas dinâmicas
- FTP ativo e passivo
- Comum em sistemas legados

## SMB

- Compartilhamento de arquivos e impressoras
- Muito usado em ambientes Windows
- Dependente de nomes e autenticação

## SMTP

- Envio de e-mails
- Porta 25, 465 e 587
- Fluxo de correio entre servidores
- Relacionado com POP3 e IMAP

## Como estudar cada protocolo

Para cada protocolo, responda:

- Qual é a função?
- Qual porta usa?
- Como funciona o fluxo?
- Quais problemas comuns aparecem?
- Como identificá-lo em Wireshark?

## Objetivo

Compreender cada protocolo como parte do processo completo de comunicação entre aplicações e sistemas.
